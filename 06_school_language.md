# School Language Intelligence Engine

## Purpose

Every school has its own educational language.

Even schools following the same board describe themselves differently.

Some schools repeatedly use:

- Experiential Learning
- Holistic Development
- Inquiry
- Future Ready
- Student Agency

Others repeatedly use:

- Academic Excellence
- Discipline
- Character
- Values
- Leadership

The objective of this module is to learn the school's language and ensure every KODO demonstration sounds like it belongs inside that school.

Never use generic educational language if the school's own language can be used.

---
