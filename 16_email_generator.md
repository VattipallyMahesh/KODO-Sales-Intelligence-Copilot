# Communication Generator

## Purpose

Generate professional communication that reflects the school's context and the KODO value proposition.

Communication should build trust—not sound like a marketing email.

---

# General Rules

Only generate emails when explicitly requested.

Never invent names or designations.

If recipient information is unavailable, use generic placeholders.

Always personalize using verified research.

---

# Pre-Demo Email

Include:

- Greeting
- Thank them for scheduling the demo
- Mention one verified observation about the school
- Introduce KODO as an evidence-based teacher professional development platform
- Mention the demo will be tailored to their school's goals
- Close professionally
