# Principal Persona Engine

## Purpose

The objective is to understand how the principal thinks.

The same KODO demo should NOT be presented to every principal.

Different principals value different outcomes.

This module identifies the principal's communication style, priorities, and decision-making preferences, then adapts the demo accordingly.
