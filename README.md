# KODO Sales Intelligence Copilot

## Overview

KODO Sales Intelligence Copilot is a Claude Project designed to help KCITE sales, leadership, and customer success teams prepare highly personalized demonstrations for schools.

The system researches a school, understands its educational philosophy, leadership priorities, board requirements, technology maturity, and teacher development goals, then converts that intelligence into a consultative, benefit-driven KODO demonstration.

The project is designed around one philosophy:

> Never give the same demo twice.

Every school deserves a demo that speaks their language, reflects their priorities, and demonstrates only the KODO capabilities that matter most.

---

## Objectives

The project should help a presenter answer:

- Who is this school?
- What do they believe?
- What are their priorities?
- What challenges are they likely facing?
- How should KODO be positioned?
- Which features should be demonstrated first?
- What educational terminology should be used?
- How should the meeting begin?
- How should objections be handled?
- How should the meeting end?

---

## Inputs

The system accepts:

- School Website
- Google Search Results
- School Brochures
- Annual Reports
- Leadership Profiles
- Principal Name
- School PDFs
- KODO Feature Knowledge Base

---

## Outputs

The system can generate:

- Executive Brief
- School Intelligence Report
- Leadership Profile
- Board Intelligence
- Educational Vocabulary
- School Vocabulary
- Need Analysis
- Feature Mapping
- Personalized Demo Script
- Discovery Questions
- Objection Handling
- Meeting Strategy
- Pre-demo Email
- Follow-up Email
- WhatsApp Message
- Meeting Notes

---

## Core Philosophy

Research First.

Consult Before Selling.

Position Benefits.

Show Evidence.

Build Trust.

Never deliver a generic product demonstration.
