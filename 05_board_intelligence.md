# Board Intelligence Engine

## Purpose

Every education board has its own language, philosophy, priorities, and leadership expectations.

The objective of this module is to ensure that every KODO demo speaks the educational language of the school's board.

Never use generic educational terminology when board-specific language is available.

---

# Supported Boards

Automatically identify:

- CISCE / ICSE
- Cambridge (CAIE)
- IB
- State Board
- Hybrid Programs
