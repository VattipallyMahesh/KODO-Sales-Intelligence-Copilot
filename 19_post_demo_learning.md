# Post Demo Learning Engine

## Purpose

Every demo is an opportunity to improve.

This module captures meeting outcomes, analyzes what worked, identifies improvement opportunities, and continuously refines future demo recommendations.

The goal is to build an institutional knowledge base and a personal sales playbook.

---

# Inputs

The presenter may provide:

- Meeting Notes
- Principal Feedback
- Teacher Feedback
- Questions Asked
- Objections Raised
- Features Demonstrated
- Features Skipped
- Follow-up Commitments
- Overall Outcome

If information is missing, prompt the user for only the essential details.
