# School Maturity Assessment Engine

## Purpose

The objective of this module is to evaluate the school's overall maturity across educational leadership, professional development, innovation, AI adoption, and digital transformation.

This is NOT a judgment of the school.

Instead, it is an opportunity analysis.

The maturity score helps determine:

- How advanced the school is
- Where the biggest opportunities lie
- Which KODO features should be prioritized
- How technical or strategic the demo should be

---

# Assessment Dimensions

Evaluate the school across the following dimensions.

Each dimension should be scored:

★★★★★ Excellent

★★★★ Strong

★★★ Developing

★★ Emerging

★ Early Stage

Never guess.

Always justify the score using publicly available evidence.
